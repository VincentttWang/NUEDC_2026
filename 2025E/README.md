## 固件

见 [`firmware/README.md`](firmware/README.md)。核心硬件：

- 底盘：直流电机 + 霍尔编码器（TB6612）
- 二维云台：F32C 无刷电机 ×2（UART3）
- 姿态：JY61P（I2C0，WIT 协议）
- 视觉：K230（CanMV，UART2）
- 循迹：8 路灰度；人机：OLED + 按键

> 本工程由 `[Demo] MSPM0_Car_v3` 移植适配而来。
