# 钢球检测模型准确度与速度汇总报告

日期：2026-08-01  
测试对象：浅层 CNN v3、YOLO11n local v4  
部署平台：Raspberry Pi 5，aarch64，NCNN 1.0.20260526，2 个 NCNN 线程

## 1. 结论摘要

- 在 387 张独立旧验证图上，两种模型均检出 383/383 张有球图，4/4 张空管图
  均无误报，存在性判断结果相同。
- 独立验证集的横向定位 P95：浅层 CNN 为 3.49 px，YOLO 为 3.53 px，基本持平；
  YOLO 的平均横向误差更低，为 0.70 px，对比 CNN 的 0.99 px。
- 在 949 张新训练样本上，两种模型均为 710/710 检出、0/239 空管误报；YOLO
  的横向 P95 为 3.25 px，CNN 为 5.60 px。该数据参与了训练，且有球标签主要由
  YOLO 辅助生成，因此不能作为独立泛化结论。
- 树莓派独占测速中，CNN 完整摄像头控制链路 P95 为 9.41 ms，YOLO 为
  26.53 ms；CNN 约快 2.82 倍。纯推理 P95 分别为 2.63 ms 和 18.40 ms，CNN
  约快 7 倍。
- 当前任务只需要固定水管内的单球存在性和横坐标，因此浅层 CNN 的性能收益明显；
  但在新增人工标注独立测试集完成前，不建议直接移除 YOLO 回退路径。

## 2. 模型与任务口径

| 项目 | 浅层 CNN v3 | YOLO v4 |
|---|---|---|
| 输入 | 原生 640×100 RGB ROI | 640×100 ROI，经 Ultralytics 预处理至 320×320 |
| 输出 | 有无球、160 格横向热图、格内偏移 | 二维检测框、类别置信度 |
| 控制使用 | 直接输出横坐标 | 取最高置信度候选的框中心 |
| 参数量 | 20,411 | 约 259 万 |
| NCNN bin | 80,044 bytes | 10,354,940 bytes |
| NCNN bin SHA-256 | `B15B3B1A79386B864F71C07D6D9C6C05EDC4322C944478059912E016CB64F2B7` | `8F460BD40E580A0452CCC0BAFA3FB068AE9E96E54D8CBACA3B513EB156FD883C` |

为公平比较，定位主表统一使用横向绝对误差。YOLO 原生的二维中心误差另行列出，
不与 CNN 的一维误差直接混用。

## 3. 准确度结果

### 3.1 独立旧验证集

数据量：383 张有球、4 张空管，共 387 张；该集合未参与 v3/v4 本轮训练。
其中动态标签部分曾由旧模型辅助生成，且独立空管样本只有 4 张，因此它适合检查
模型回退，但仍不是充分的最终泛化测试集。

| 模型 | 有球检出 | Recall | 空管误报 | 横向均值 | 横向 P95 | 横向最大值 |
|---|---:|---:|---:|---:|---:|---:|
| 浅层 CNN v3 | 383/383 | 100% | 0/4 | 0.99 px | **3.49 px** | **6.37 px** |
| YOLO v4，conf=0.25 | 383/383 | 100% | 0/4 | **0.70 px** | 3.53 px | 7.51 px |

YOLO 的二维中心误差为：均值 0.96 px、P95 3.91 px、最大 7.79 px。

结论：两者检出结论相同；YOLO 平均横向误差更低，CNN 的横向 P95 略低
0.04 px。该差异很小，可认为独立验证集上的横向定位精度基本持平。

### 3.2 新数据去重并集

数据量：710 张有球、239 张空管，共 949 张。`actual_video_frames_raw_new_v2`
已经完整包含 `actual_video_frames_raw_new` 的 375 张样本；训练时没有重复使用。

| 模型 | 有球检出 | Recall | 空管误报 | 横向均值 | 横向 P95 | 横向最大值 |
|---|---:|---:|---:|---:|---:|---:|
| 浅层 CNN v3 | 710/710 | 100% | 0/239 | 1.73 px | 5.60 px | 27.91 px |
| YOLO v4，conf=0.25 | 710/710 | 100% | 0/239 | **0.99 px** | **3.25 px** | **25.60 px** |

YOLO 的二维中心误差为：均值 1.30 px、P95 4.27 px、最大 25.63 px。

限制：该集合参与了两种模型训练，而且正样本标签主要由 YOLO v3 辅助生成，
定位指标天然偏向 YOLO。此表只用于检查训练拟合和明显回归，不能证明 YOLO 的
独立泛化精度优于 CNN。

### 3.3 树莓派实时画面

独占测速的 130 个不同摄像头帧中：

- CNN：130/130 帧检出，每帧输出一个横坐标；
- YOLO：130/130 帧有检出，但每帧返回 2 个候选，共 260 个候选；
- 生产逻辑仍需保持“只取最高置信度候选”。

实时测速画面没有逐帧人工真值，只能证明当前场景连续检出，不能当作准确率测试集。

## 4. Raspberry Pi 5 独占速度

测试时临时停止 `vision-scale-uart.service`，保留摄像头所需的
`ustreamer.service`；测试退出时自动恢复 UART 服务。两种模型依次运行，均使用
2 个 NCNN 线程、OpenCV 1 线程，无并行模型竞争。

### 4.1 静态 ROI，30 次预热、500 次测量

| 指标 | 浅层 CNN v3 | YOLO v4 | CNN 加速比 |
|---|---:|---:|---:|
| 纯推理均值 | 2.25 ms | 17.72 ms | 7.87× |
| 纯推理 P95 | **2.39 ms** | 18.06 ms | **7.55×** |
| 完整调用均值 | 2.91 ms | 19.69 ms | 6.77× |
| 完整调用 P95 | **3.08 ms** | 20.04 ms | **6.50×** |
| P95 等效帧率 | 324.6 fps | 49.9 fps | 6.50× |
| 最大 RSS | 71.7 MiB | 412.8 MiB | CNN 约为 1/5.8 |

CNN 完整调用包含 BGR→RGB/CHW、NCNN 推理和坐标解码；YOLO 完整调用包含
Ultralytics 预处理、NCNN 推理和检测后处理。

### 4.2 真实摄像头链路，10 次预热、130 帧测量

链路包括 `/snapshot` 取帧、JPEG 1/2 解码、640×100 局部鱼眼校正、模型推理和
坐标/检测结果输出。

| 指标 | 浅层 CNN v3 | YOLO v4 | CNN 加速比 |
|---|---:|---:|---:|
| 模型纯推理均值 | 2.49 ms | 18.12 ms | 7.29× |
| 模型纯推理 P95 | **2.63 ms** | 18.40 ms | **6.99×** |
| 模型完整调用 P95 | 约 3.15 ms | 20.42 ms | 约 6.5× |
| 摄像头到结果均值 | 9.22 ms | 26.28 ms | 2.85× |
| 摄像头到结果 P95 | **9.41 ms** | 26.53 ms | **2.82×** |
| 帧时间戳到结果 P95 | 9.48 ms | 26.69 ms | 2.81× |
| 控制频率 | **106.2 fps** | 37.7 fps | 2.82× |
| 最大 RSS | 75.8 MiB | 414.9 MiB | CNN 约为 1/5.5 |

测试最高温度 59.3°C，`throttled=0x0`，无降频。结束后 `ustreamer` 与
`vision-scale-uart` 均恢复为 active。

## 5. 生产负载下速度

在原生产 YOLO v3 UART 服务保持运行时，再额外启动被测模型：

| 指标 | 浅层 CNN v3 | YOLO v4 |
|---|---:|---:|
| 静态完整调用 P95 | 6.18 ms | 36.26 ms |
| 摄像头到结果 P95 | 14.62 ms | 40.52 ms |
| 等效控制频率 | 68.4 fps | 24.7 fps |

该结果反映 shadow/并行运行负载。YOLO v4 相当于与生产 YOLO v3 同时执行，不能
用作单模型独占速度；正式速度结论应以第 4 节为准。

## 6. 综合评价

| 维度 | 更优模型 | 判断 |
|---|---|---|
| 有球检出 | 持平 | 独立验证均为 383/383 |
| 空管抑制 | 暂时持平 | 独立验证均为 0/4，但独立负样本太少 |
| 平均横向误差 | YOLO | 0.70 px 对 0.99 px |
| 横向 P95 | 基本持平 | CNN 3.49 px，YOLO 3.53 px |
| 推理速度 | CNN | 独占摄像头纯推理约快 7 倍 |
| 完整控制链路 | CNN | 独占 P95 约快 2.82 倍 |
| 内存和模型大小 | CNN | RSS 约 1/5.5，权重约 1/129 |
| 二维框输出 | YOLO | CNN 只针对存在性和横坐标 |
| 多候选行为 | CNN | YOLO 当前实时画面出现每帧 2 个候选 |

## 7. 建议

1. 当前固定水管、单钢球、控制只需要横坐标的条件下，优先将浅层 CNN v3 作为
   高频控制候选模型。
2. 首次部署保留 YOLO 回退或 shadow 对照，不立即删除现有生产模型。
3. 新录制至少一段有球和一段空管视频，整段不参与训练，由人工标注形成真正独立
   测试集；重点覆盖倾角、振动、光照、左右边界和短时遮挡。
4. 独立验收门槛建议至少包括：有球检出率、空管误报率、横向 P95/最大误差、最长
   连续漏检和实时多候选率。
5. 复查 YOLO v4 当前每帧双候选的类别、位置和置信度，确认是重叠框还是固定结构
   误检，再决定阈值或 NMS 调整。
