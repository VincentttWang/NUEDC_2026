# 赛道参数作用与约束说明

本页说明树莓派赛道参数调试台中的 13 个参数。它们只影响 H2、H5、H6；H4 不读取这些参数。

所有参数只保存在 MSPM0 的 RAM 中。MSPM0 上电或复位后会恢复固件编译期默认值，不会自动读取树莓派保存的方案。每次重新上电后，应在小车主菜单/闲置态重新应用赛场方案，并以“读取全部”的结果为准。

## 使用前须知

- 距离参数的单位均为 mm。
- 前馈参数使用千分比定点数，例如 1100 表示 1.100 倍。
- SET 和恢复默认值只在 MSPM0 主菜单状态生效；任务运行中会返回 BUSY。
- 固件只检查参数 ID，不替树莓派检查数值范围和参数关系。
- 超出建议范围不一定无效，但可能明显改变车辆行为，应用会要求二次确认。
- H2/H5/H6 进入任务时会复制一次完整参数快照；任务过程中修改不会改变该次任务正在使用的快照。

## 优先级 1：分段阈值与回正

### s1_end_mm（ID 0x0101）

作用：S1 到 S2 的切换里程。车辆累计里程到达该值后进入第一弯相关阶段。

- 默认值：1500 mm
- 建议范围：1300～1700 mm
- 主要约束：必须小于 s2_end_mm
- 调整风险：过小会提前入弯，过大会延后入弯

### s2_end_mm（ID 0x0102）

作用：S2 到 S3 的切换里程，也是第一弯结束及回正窗口的起点。

- 默认值：3071 mm
- 建议范围：2750～3400 mm
- 主要约束：s1_end_mm < s2_end_mm < s3_end_mm
- 联动关系：s2_end_mm + s3_gyro_recover_mm 应小于 s3_end_mm

### s3_end_mm（ID 0x0103）

作用：S3 到 S4 的切换里程，决定回正/直行阶段何时结束并进入第二弯阶段。

- 默认值：4641 mm
- 建议范围：4200～5000 mm
- 主要约束：s2_end_mm < s3_end_mm < s4_heading_end_mm
- 调整风险：过小可能压缩回正窗口，过大会推迟第二弯

### s4_heading_end_mm（ID 0x0104）

作用：S4 航向参考完成 360° 时的绝对里程。

- 默认值：6212 mm
- 建议范围：5600～6800 mm
- 主要约束：必须大于 s3_end_mm
- 推荐关系：不大于 lap_stop_mm

### s3_gyro_recover_mm（ID 0x0105）

作用：S2 结束后使用陀螺仪保持直行、完成车身回正的距离。

- 默认值：300 mm
- 建议范围：0～600 mm
- 联动关系：s2_end_mm + 本值应小于 s3_end_mm
- 调整风险：窗口过长会覆盖下一阶段，过短可能来不及回正

## 优先级 2：终点与停车

这组参数没有统一的固定推荐范围，应根据赛场实际里程、横线识别位置和车辆制动距离确定。

### lap_stop_mm（ID 0x0110）

作用：A 点减速和横线停车判断使用的绝对里程参考，是多个终点参数的基准。

- 默认值：6242 mm
- 推荐关系：s4_heading_end_mm <= lap_stop_mm
- 推荐关系：lap_stop_mm <= loaded_odom_arrival_mm
- 推荐关系：lap_stop_mm <= h2_odom_fallback_mm
- 注意：loaded_odom_arrival_mm 和 h2_odom_fallback_mm 服务不同任务，不要求二者互相绑定

### finish_arm_margin_mm（ID 0x0111）

作用：横线检测的提前武装距离。实际武装起点为：

```
lap_stop_mm - finish_arm_margin_mm
```

- 默认值：400 mm
- 硬约束：不得大于 lap_stop_mm
- 调整风险：过大可能过早响应非终点横线，过小可能来不及稳定识别 A 点横线

### loaded_decel_warning_mm（ID 0x0112）

作用：H5/H6 载球任务的减速提前量。实际减速起点为：

```
lap_stop_mm - loaded_decel_warning_mm
```

- 默认值：250 mm
- 硬约束：不得大于 lap_stop_mm
- 调整风险：过小可能制动距离不足，过大可能明显损失用时

### loaded_odom_arrival_mm（ID 0x0113）

作用：H5/H6 使用编码器判断车辆到达 A 点的绝对里程。

- 默认值：6342 mm
- 推荐关系：不小于 lap_stop_mm
- 适用任务：H5/H6，不与 H2 兜底值强制绑定

### h2_odom_fallback_mm（ID 0x0114）

作用：H2 未检测到 A 点横线时，使用编码器里程执行兜底停车。

- 默认值：6442 mm
- 推荐关系：不小于 lap_stop_mm
- 调整风险：过小可能抢在横线识别前停车，过大则会增加漏检后的越界距离

## 优先级 3：弯道前馈

前馈值为千分比定点数。850 表示 0.850 倍，1000 表示 1.000 倍，1300 表示 1.300 倍。

### h2_s2_ff_x1000（ID 0x0120）

作用：H2 第一弯使用的前馈倍率。

- 默认值：1100（1.100 倍）
- 建议范围：850～1300
- 调整方向：增大通常会增强第一弯的预置转向作用，减小则减弱

### loaded_s2_ff_x1000（ID 0x0121）

作用：H5/H6 载球任务第一弯使用的前馈倍率。

- 默认值：1000（1.000 倍）
- 建议范围：850～1300
- 注意：载球和空载动力学不同，不应直接假定与 H2 使用相同数值

### s4_ff_x1000（ID 0x0122）

作用：H2/H5/H6 第二弯共同使用的前馈倍率。

- 默认值：1000（1.000 倍）
- 建议范围：850～1300
- 调整风险：该值同时影响三个任务，修改后应分别复测

## 应用检查规则

应用会阻止以下明显错误：

- 任意值不是 0～65535 的整数
- 不满足 s1_end_mm < s2_end_mm < s3_end_mm < s4_heading_end_mm
- finish_arm_margin_mm 大于 lap_stop_mm
- loaded_decel_warning_mm 大于 lap_stop_mm

应用会对以下情况显示警告，并要求再次确认：

- 优先级 1 或 3 参数超出建议范围
- s2_end_mm + s3_gyro_recover_mm >= s3_end_mm
- s4_heading_end_mm > lap_stop_mm
- lap_stop_mm > loaded_odom_arrival_mm
- lap_stop_mm > h2_odom_fallback_mm

## 推荐调试流程

1. 确认小车停在主菜单/闲置态。
2. 点击“读取全部”，记录 MSPM0 当前实际值。
3. 每次只修改少量相关参数，点击“应用改动”。
4. 等待应用自动完成 SET 和 GET_ALL 回读核对。
5. 进入任务实测；任务结束并回到主菜单后再继续调整。
6. 参数稳定后保存赛场方案。
7. MSPM0 复位后，重新加载方案、应用改动并再次读取全部。

恢复固件默认值只修改 MSPM0 RAM，不会删除树莓派上保存的赛场方案。
