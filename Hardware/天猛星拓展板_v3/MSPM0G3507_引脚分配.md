# MSPM0G3507 引脚分配速查

资料来源：`拓展板原理图_v3.pdf`，原理图标题为“天猛星--电赛小车拓展板_2”，板子版本 `天猛星v3`，更新日期 `2026-07-07`。

说明：

- 原理图中的 `Axx` / `Bxx` 对应 MSPM0G3507 的 `PAxx` / `PBxx`。
- `GND`、`5V`、`3V3`、`12V-IN`、`5V-IN`、`5V-Servo` 是电源网络，不是 MCU GPIO。
- `DIO`、`CLK`、`RST`、`CHIP` 是核心板调试/复位/启动相关信号，使用前应核对核心板定义。
- 表中 `NC` 表示原理图未标注连接或未接出有效网络。
